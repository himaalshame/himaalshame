### 📋 CRM System — Client & Workflow Management

A business management system that coordinates work from service request through delivery and payment tracking.

- **Clients, services & orders:** centralized management in one place
- **Approval workflow:** structured order review before work starts
- **Project tracking:** status updates and employee assignment

- Request validation and consistent error handling
- Typed data access with Prisma + PostgreSQL
